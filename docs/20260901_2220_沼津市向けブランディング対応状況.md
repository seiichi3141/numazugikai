## シードの作り替え

`pnpm db:reset` のたびに国会の架空法案（ガソリン税法案など）が復活し、
「公開サイトを見たら国会のデータが並んでいる」という混乱を実際に招いていた。
シードの役割を次のように変えて解消した。

- **議案・会期はシードで作らない。** 取り込み（`@mirai-gikai/numazu-ingest`）に委ねる
- シードが作るのは admin ユーザー・タグ・デモのインタビューデータのみ
- デモは取り込み済みの**実在の議案に紐づける**。議案が無ければタグだけ作って
  デモはスキップし、エラーにはしない
- `clearAllData` の対象から `bills` / `council_sessions` を外した。
  ここに含めると `pnpm seed` が取り込み済みの実データを消してしまう
- 本家の国会データCSV（`packages/seed/csv/`）は削除。
  現スキーマに存在しない `originating_house` / `diet_session_id` /
  `shugiin_url` を持ち既に動作不能で、かつ国会データの復活経路だった

タグは議案の種別（`bills.category` が持つ）ではなく「暮らしのどの分野か」という
テーマ軸にした: 子育て・教育 / 医療・福祉 / 暮らし・まちづくり / 防災・安全 /
産業・観光 / 行財政・人事。議案名のキーワード判定で187議案中169件に付く。

### 途中で見つけた既存バグ

トピック分析デモの `source_message_id` の紐づけが壊れていた。
bulk insert では全行の `created_at` が同一になり `id` は UUID のため、
「N番目の意見 = N番目の発言」という対応づけが成立していなかった
（実測で300意見中210件が別人の発言を指していた）。
(セッションID, 本文) をキーにした引き当てに変更し、実データで不整合0件を確認した。

## 本フェーズで手を付けなかった既存の規約違反

`AGENTS.md` は生の `<button>` とインラインSVGを禁止しているが、
本家から引き継いだコードに違反が残っている（本フェーズの文言変更とは無関係）。
スコープを広げると見た目の回帰リスクが出るため別タスクとする。

- 生の `<button>`: 16箇所
- インラインSVG: 11箇所
- 主な該当: `review-status-banner.tsx`, `bill-share-modal.tsx`,
  `interview-chat-input.tsx`, `quick-reply-buttons.tsx`,
  `user-topic-analysis/shared/components/*-icon.tsx`

なお `users-three-icon.tsx` などアイコン専用コンポーネントのインラインSVGは、
`lucide-react` に同等のアイコンが無い場合は例外として許容してよい。
