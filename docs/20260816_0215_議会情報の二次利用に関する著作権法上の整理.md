# 議会情報の二次利用に関する著作権法上の整理

- 作成日: 2026-08-16
- 関連: [20260816_0132_沼津市議会向け改修要件定義と実装計画.md](./20260816_0132_沼津市議会向け改修要件定義と実装計画.md) の 3.7 節を本書で全面的に置き換える
- **注意: 筆者は弁護士ではない。本書は公開情報に基づく整理であり、法的助言ではない。サービス公開前に専門家のレビューを受けること（9章）。**

---

## 1. 結論

先行ドキュメントで「沼津市サイトの『二次利用禁止』表示が最大のブロッカー」としたのは**整理が粗かった**。逐条で検討すると、本サービスが必要とする利用のほとんどは、**市の許諾がなくても著作権法上適法に行える**。

| 扱うもの | 結論 | 根拠 |
| :-- | :-- | :-- |
| 議案番号・件名・提出者・付託委員会・議決結果・日付 | **自由に利用可** | そもそも著作物でない（事実） |
| 会派別賛否（議会だよりの表から抽出した事実） | **自由に利用可**（表のレイアウトを模倣しない限り） | 同上 |
| 成立した条例の本文 | **自由に利用可** | 著作権法13条1号（法令は権利の目的とならない） |
| 議案（条例案）の条文 | **ほぼ自由に利用可** | 表現の選択の幅が狭く著作物性を認めがたい。議決・公布後は13条1号で完全に自由 |
| 議会での発言（会議録・中継の音声内容） | **学説が割れる。**1項説なら自由、2項説ならウェブ掲載は不可 | 著作権法40条1項／2項（3.3） |
| 議会での発言を**情報解析**（AIで分類・要約の材料に）する | **自由に行える** | 著作権法30条の4第2号 |
| 解析結果として**AIが独自の表現で書いた解説** | **自由に公開できる** | 原著作物の表現を再現しない限り、そもそも複製・翻案に当たらない |
| 議会だより・広報資料の**転載** | **不可**（禁止表示があるため32条2項の適用外）。ただし**引用**（32条1項）は可 | 著作権法32条 |
| 議会中継の**映像そのもの** | 沼津市に帰属（職務著作）。転載不可、埋め込み・リンクで対応 | 著作権法15条1項 |

**サイトに書かれた「無断転載禁止」は、著作権法が認める利用（引用・情報解析・政治上の演説の利用など）を封じる効力を持たない。** 一方的な意思表示であって契約ではなく、権利制限規定は当事者の意思で排除できないためである。

したがって計画の修正は次のとおり。

- 「市の許諾が下りるまで Phase 3 に進まない」という前提を**撤回**する。設計上の制約を守る限り、許諾を待たずに実装・公開できる。
- 市への働きかけは「**使わせてください**」という許諾のお願いではなく、「**議会データをオープンデータとして公開しませんか**」という提案に切り替える。同じ静岡県内の**御殿場市が既に「市議会の状況」を CC BY で公開している**（6.4）ため、要望の説得力がある。
- ただし**議会での発言の扱いだけは慎重を要する**（3.3）。ここは学説が真っ二つに割れており、設計で回避する（7章）。

## 2. なぜ前回の整理が不正確だったか

前回はサイトの著作権表示だけを見て「二次利用禁止 → 使えない」と結論づけた。誤りは2点。

1. **著作権法の権利制限規定を検討していなかった。** 著作権は絶対的な権利ではなく、法が明文で認める利用（引用、情報解析、政治上の演説の利用など）は権利者の意思にかかわらず適法である。サイトの表示でこれを覆すことはできない。
2. **「著作権は沼津市に帰属します」という包括表示を額面どおり受け取っていた。** 実際には、議会での**議員の発言の著作権は発言した議員個人に帰属**し、沼津市には帰属しない（3.3）。また条例の本文には**そもそも著作権が発生しない**（3.2）。市の包括表示は、少なくとも議会情報については法的に正確でない。

議会の情報は、地方自治法が会議の公開と会議録の作成・公開を義務づけ、住民が知るために存在する。「市民が使えない」という帰結が直感に反するのは正しく、法の建て付けもそうはなっていない。

## 3. 対象別の逐条検討

### 3.1 事実データ — 著作物ではない

著作権法2条1項1号は著作物を「思想又は感情を**創作的に表現**したもの」と定義する。以下は事実であって思想・感情の創作的表現ではないため、著作物ではなく、著作権は及ばない。

- 議案番号（議第58号）、議案名、提出日、提出者、付託委員会、委員会審査結果、議決日、審議結果
- 会期の開会日・閉会日、定例会の回次
- 議員の氏名・会派・議席番号・所属委員会
- 会派別の賛否（○×）

**編集著作物（12条1項）の問題**は残るが、議案審議結果 PDF は「地方自治法第96条の分類 → 議案番号順」という法定・機械的な配列であり、素材の選択・配列に創作性を認めるのは難しい。念のため、**取り込んだ事実を自前のデータモデルに再構成し、元 PDF の表レイアウトを模倣しない**運用にすれば、編集著作物の議論も回避できる。

> **設計上の帰結**: 議案・議決結果・会派別賛否は、**PDF から抽出して DB に持ち、自サービスの形式で表示してよい**。出典表示はマナーとして必ず行う（法的義務ではないが、信頼性のために必須）。

### 3.2 条例・条例案の本文 — 13条1号

```
著作権法第13条 次の各号のいずれかに該当する著作物は、この章の規定による権利の目的となることができない。
 一 憲法その他の法令
 二 国若しくは地方公共団体の機関、独立行政法人又は地方独立行政法人が発する告示、訓令、通達その他これらに類するもの
 三 裁判所の判決、決定、命令及び審判 …（略）
 四 前三号に掲げるものの翻訳物及び編集物で、国若しくは地方公共団体の機関 …が作成するもの
```

**条例・規則は1号の「法令」に含まれる**というのが通説である。したがって、成立した沼津市の条例本文は著作権の対象外であり、全文を掲載しても改変しても構わない（沼津市例規集の内容も同様）。

議決前の**条例案**は厳密には「法令」ではない。しかし条例案の条文は法制執務の作法に厳格に縛られており表現の選択の幅がほぼ無い（ありふれた表現）ため、著作物性を認めがたい。加えて議決・公布されれば1号で完全に自由になる。**実務上のリスクは低い。**

予算書・決算書の数値、新旧対照表も同様に事実・データである。

> **設計上の帰結**: 条例本文を `knowledge_source` として保存し AI のコンテキストに使うことに、著作権上の障害はない。

### 3.3 議会での発言 — 40条。ここだけが本当の論点

まず**著作権が誰に帰属するか**。一般財団法人 地方自治研究機構の自治体法務 Q&A は次のように整理する。

- 創作性のある質疑応答・答弁は著作物として保護される
- **議員**の質疑・討論 → **その議員個人**が著作者。著作権は議員に帰属する
- **市長・市職員**の答弁 → 職務著作（15条1項）として**地方公共団体（沼津市）**に帰属
- 議会中継の**映像** → 議会事務局職員が作成するため職務著作。沼津市に帰属
- 「議会」自体は権利能力を持たないため、議会に著作権が帰属することはない

つまり**沼津市サイトの「著作権は沼津市に帰属します」は、議員の発言部分については誤り**である。

次に**40条による権利制限**。条文は以下のとおり。

```
著作権法第40条（公開の演説等の利用）
第1項 公開して行われた政治上の演説又は陳述並びに裁判手続及び行政審判手続における公開の陳述は、
       同一の著作者のものを編集して利用する場合を除き、いずれの方法によるかを問わず、利用することができる。
第2項 国若しくは地方公共団体の機関、独立行政法人又は地方独立行政法人において行われた公開の演説又は陳述は、
       前項の規定によるものを除き、報道の目的上正当と認められる場合には、新聞紙若しくは雑誌に掲載し、
       又は放送し、有線放送し、地域限定特定入力型自動公衆送信を行い、若しくは放送同時配信等を行うことができる。
```

**この2項の差が決定的である。**

| | 適用される条項 | 許される利用 |
| :-- | :-- | :-- |
| 1項が適用されるなら | 40条1項 | **「いずれの方法によるかを問わず」利用可。ウェブ掲載も含む。** ただし「同一の著作者のものを編集して利用する場合」は除外 |
| 2項のみなら | 40条2項 | 報道目的で、新聞・雑誌への掲載か放送等に限られる。「放送等」は放送事業者向けの概念であり、**一般のウェブサイトへの掲載は含まれない** |

そして学説・実務は割れている。

**1項適用を認める立場**（国立国会図書館）
国会会議録検索システムのヘルプ「利用条件・免責事項」は、発言の著作権は個々の発言者に帰属するとしたうえで、以下の権利制限規定が適用される場合は許諾なく利用できると明記している。

> 私的使用のための複製、引用、**政治上の演説又は陳述に該当する箇所の利用**、報道、**電子計算機による情報解析** 等

国の機関が公式に「政治上の演説又は陳述に該当する箇所」として40条1項の適用を認めている点は、実務上の強い後ろ盾になる。

**1項適用を否定する立場**（地方自治研究機構）

> 議会における質疑応答や答弁等については同条1項の適用はないという見解が有力

理由は明示されていないが、体系解釈としては「40条2項がわざわざ『地方公共団体の機関において行われた公開の演説又は陳述』を別に規定している以上、議場での発言は2項の守備範囲であって1項の『政治上の演説』とは区別される」という理解と思われる。同機構は、ウェブへのアップロードには原則として議員の許諾が必要であり、**議会であらかじめ申し合わせをしておくのがよい**と実務的な助言をしている（なおこの Q&A は2013年のもので、令和3年改正前の条文を前提にしている点に留意）。

**評価**

条文を素直に読めば、2項の「前項の規定によるものを除き」は、**議会での発言であっても「政治上の演説又は陳述」に当たるものには1項が優先適用される**という構造を示している。市長の施政方針演説や議員の討論は政治的主張の表明そのものであり、1項に当たると解する余地は十分ある。他方で、事務的な議事進行の発言や事実確認の答弁は「政治上の演説又は陳述」とは言い難い。

**要するに、発言の性質によって1項に当たるものと当たらないものが混在する**というのが実態に近く、会議録を一律に扱う判断はどちらの立場でもリスクが残る。

> **設計上の帰結（7章で詳述）**
> - 会議録の**全文をそのまま掲載しない**。原文は沼津市の会議録検索システム・議会中継へリンクする。
> - **議員個人の発言だけを集めたページを作らない。** これは40条1項が適用される場合でも、ただし書き「同一の著作者のものを編集して利用する場合」に該当し、明確に適用除外になる。**議員別の発言アーカイブは、40条のどちらの説に立っても作れない。**
> - 解析（30条の4）と、AI が独自表現で書いた要約・論点整理の公開（3.6・3.7）に軸足を置く。これは40条の解釈に依存しない。

### 3.4 議会だより・広報資料 — 32条

```
著作権法第32条
第1項 公表された著作物は、引用して利用することができる。この場合において、その引用は、公正な慣行に合致するものであり、
       かつ、報道、批評、研究その他の引用の目的上正当な範囲内で行なわれるものでなければならない。
第2項 国若しくは地方公共団体の機関 …が一般に周知させることを目的として作成し、その著作の名義の下に公表する広報資料、
       調査統計資料、報告書その他これらに類する著作物は、説明の材料として新聞紙、雑誌その他の刊行物に転載することができる。
       ただし、これを禁止する旨の表示がある場合は、この限りでない。
```

「ぬまづ市議会だより」は2項の「広報資料」に当たる。しかし沼津市サイトの著作権ページに「無断使用・転載、二次利用を禁止します」と明記されており、これは2項ただし書きの「**これを禁止する旨の表示**」に当たると解するのが素直である。したがって **32条2項による転載はできない。**

一方、**32条1項の引用は使える。** 引用は「禁止する旨の表示」で排除できない権利制限であり、以下の要件を満たせば適法である。

- 引用する必然性があること
- 自己の著作物と引用部分が明瞭に区別されていること
- 自己の著作物が主、引用部分が従であること（主従関係）
- 引用の目的上正当な範囲内であること
- 出所を明示すること（48条1項）

> **設計上の帰結**: 議会だよりから**会派別賛否という事実を抽出して自前の表にする**のは転載でも引用でもなく、そもそも著作権が及ばない（3.1）。議会だよりの文章そのものを載せたい場合のみ、引用の要件を厳格に満たす形にする。

### 3.5 議会中継の映像 — 沼津市に帰属

職務著作（15条1項）として沼津市に著作権が帰属する。**動画ファイルの転載・再配信は不可。** DiscussVision の該当再生ページへリンクする、または公式が提供する埋め込み手段があればそれを使う。

なお発言の**内容**（言語の著作物）と映像（映画の著作物）は別の著作物であり、内容の扱いは3.3の議論による。

### 3.6 AI による情報解析 — 30条の4

```
著作権法第30条の4
著作物は、次に掲げる場合その他の当該著作物に表現された思想又は感情を自ら享受し又は他人に享受させることを
目的としない場合には、その必要と認められる限度において、いずれの方法によるかを問わず、利用することができる。
ただし、当該著作物の種類及び用途並びに当該利用の態様に照らし著作権者の利益を不当に害することとなる場合は、この限りでない。
 二 情報解析（多数の著作物その他の大量の情報から、当該情報を構成する言語、音、影像その他の要素に係る情報を抽出し、
   比較、分類その他の解析を行うことをいう。…）の用に供する場合
```

**議案 PDF や会議録を取得して LLM に投入し、論点を分類・抽出・要約の材料にする行為は、典型的な「情報解析」である。** 国会図書館も権利制限規定の一つとして明記している。

ただし但し書きに注意。「著作権者の利益を不当に害する」場合は適用されない。議会情報については、市が販売しているわけでも市場が存在するわけでもないため、不当に害する余地は乏しい。

**重要な限界**: 30条の4は「思想又は感情を自ら享受し又は他人に享受させることを目的としない場合」に限られる。**解析結果として原文をそのまま読ませる**なら、それは享受目的なので30条の4では正当化できない。あくまで**解析の過程での複製**を正当化する規定である。

> **設計上の帰結**: 取り込み・解析パイプラインの中で原文を一時的に保持することは適法。**原文をそのままユーザーに配信しない**設計にすることで、30条の4の枠内に収まる。

### 3.7 AI が生成した解説の公開 — そもそも著作権が及ばない

著作権は**表現**を保護し、**アイデア・事実**は保護しない。

- 「議第58号は印鑑条例の一部改正で、可決された」→ 事実。自由
- 「この改正はマイナンバーカードでのコンビニ交付に対応するもので、市民にとっては手数料が変わる点が要点」→ AI（または運営者）が原文を読んだうえで**自分の言葉で書いた表現**。新たな著作物であり、原文の複製でも翻案でもない

翻案（27条）に当たるのは、原著作物の**表現上の本質的特徴を直接感得できる**場合である。原文の言い回しを再現せず、事実と論点だけを抽出して独自に構成した解説は、これに当たらない。

**これが本サービスの中核であり、法的に最も安全な領域でもある。** 「議会の一次資料を読み解いて、市民に分かる言葉で説明し直す」という行為そのものが、著作権法上ほぼ自由に行える。

なお文化庁「AIと著作権に関する考え方について」（2024年3月）は、生成・提供段階については通常の著作権侵害の枠組み（類似性＋依拠性）で判断するとしており、上記の整理と整合する。

## 4. 「無断転載禁止」表示の法的効力

サイトに「無断使用・転載、二次利用を禁止」と書いてあっても、以下は覆せない。

| 覆せないもの | 理由 |
| :-- | :-- |
| 32条1項の引用 | 権利制限規定であり、権利者の一方的意思表示で排除できない |
| 30条の4の情報解析 | 同上 |
| 40条の公開の演説等の利用 | 同上 |
| 13条により著作権が発生しないもの（法令等） | そもそも権利がない |
| 事実・アイデアの利用 | そもそも著作物でない |

**覆せるもの**は、条文自身が「禁止する旨の表示がある場合はこの限りでない」と定めているもの（32条2項の転載、35条の一部など）だけである。

サイト表示が法的意味を持つのは、(a) 上記の明文の除外にあたる場合、(b) 利用規約への同意という**契約**が成立している場合、の2つ。沼津市サイトは閲覧にあたり同意を求めるフローを持たないため、(b) の契約構成は成り立ちにくい。

とはいえ、法的に適法であることと、市との関係を良好に保つことは別問題である。**法的には許諾不要でも、事前に一報を入れて関係を作るほうが、長期的にはデータ提供の改善につながる**（8章）。

## 5. 個人情報・名誉毀損など著作権以外の論点

著作権をクリアしても以下は別途検討が必要である。

| 論点 | 内容 | 対応 |
| :-- | :-- | :-- |
| 議員の個人情報 | 議員一覧 PDF には**自宅住所・電話番号**が含まれる | **取り込まない。** 氏名・会派・議席番号・所属委員会・党派に限定する（4.4 のスキーマは既にそうしている） |
| 陳情者・請願者の氏名 | 請願・陳情の提出者名 | 公開情報だが、サービス上で強調しない。氏名は取り込まない方針を推奨 |
| 会議録の伏せ字 | 沼津市は個人情報保護の観点から発言の一部を伏せて「会議記録」として公開しており、正式な「会議録」とは異なる旨を明示している | 伏せられた箇所を推測・補完しない。出典が「会議記録」である旨を表示する |
| 名誉毀損・議員の評価 | AI が議員や会派の姿勢を要約・評価する場合 | 事実の摘示と論評を区別する。断定を避け、根拠となる一次資料へリンクする。誤りの申告・訂正の窓口を設ける |
| 公職選挙法 | 選挙期間中の特定候補への言及 | 選挙期間中は議員個別の評価表示を停止する運用を検討 |
| 誤情報のリスク | AI 生成の解説が誤って市政の理解を歪める | 人のレビューを公開の必須ゲートにする（計画書 5.3）。誤りの訂正フローを用意する |

## 6. 制度的な後押し

### 6.1 議事公開の原則

地方自治法115条1項は議会の会議を公開と定め、同法123条は議長に会議録の作成を義務づける。総務省は、この規定の趣旨を「住民の求めに応じて閲覧させることなどにより、議事公開の原則を全うすること」とし、**会議録のホームページ上での公開等に積極的に取り組むことが重要**としている。

議会情報は「市民が知るために」制度上公開されている。二次利用を過度に制限する運用は、この趣旨と整合しない。

### 6.2 オープンデータ基本指針

政府の「オープンデータ基本指針」（2017年決定、2024年7月改正）は、国・自治体が保有するデータを機械判読可能な形式で、二次利用可能なルールのもとで公開することを原則としている（オープンデータ・バイ・デザイン）。

### 6.3 公共データ利用規約（第1.0版）

デジタル庁の「公共データ利用規約（第1.0版）」（2024年7月）および従来の「政府標準利用規約（第2.0版）」は、いずれも **CC BY 4.0 と互換**の利用条件を標準とする。地方公共団体へのアンケートでは、政府標準利用規約2.0 または CC BY 4.0 を採用する自治体が**約45%**を占める。

### 6.4 【重要】御殿場市の先例 — 同じ静岡県内で議会データが CC BY 公開されている

静岡県オープンデータカタログに、**御殿場市議会事務局（議事課）が作成した「市議会の状況」データセット**が登録されている。

- 提供: 御殿場市
- ライセンス: **クリエイティブ・コモンズ表示（CC BY）**
- 形式: CSV（`22215_city_council.csv`）+ **Web API**
- 更新頻度: 年1回程度
- 最終更新: 2026年1月22日
- 作成部署: **議事課**

つまり「議会のデータをオープンデータとして CC BY で出す」ことは、静岡県内で既に前例があり、県のカタログ基盤もそのまま使える。一方、**沼津市がふじのくにオープンデータカタログに登録しているのは統計書のみで、議会関連データは1件もない**（本調査時点）。

**これは市への提案において最も効く材料である。** 「他県の話」ではなく「同じ県内の隣接自治体が、同じカタログで、議事課の手でやっている」と示せる。

### 6.5 先行事例

- **chiholog（地方議会議事録横断検索）** — 798自治体の会議録を収集して全文検索・単語頻度分析を提供し、VLED 利活用・普及委員会から表彰を受けた。サイト上で著作権法13条に言及して法的立場を明示していた（2016〜2019年、現在は終了）
- **地方議会会議録コーパスプロジェクト（local-politics.jp）** — 会議録の横断検索・自動要約・意見抽出の研究基盤
- **国立国会図書館 国会会議録検索システム API** — 会議単位・発言単位でデータ取得可能な公式 API

議会会議録を収集・解析して公開するサービスは既に複数存在し、表彰まで受けている。**前例のない挑戦ではない。**

## 7. 設計への落とし込み

法的整理を踏まえた実装ルール。計画書 5章のパイプライン設計に組み込む。

### 7.1 やってよいこと（許諾不要）

| # | 内容 |
| :-- | :-- |
| A1 | 議案番号・件名・提出者・付託委員会・議決結果・日付を抽出して DB に保持し、自サービスの形式で表示する |
| A2 | 会派別賛否を議会だよりから抽出し、自前の表で表示する |
| A3 | 条例本文・議案本文を取得し `knowledge_source` として保持し、AI のコンテキストに使う |
| A4 | 会議録・議案を LLM に投入して論点抽出・分類・要約の材料にする（30条の4） |
| A5 | AI（または運営者）が独自の表現で書いた解説・論点整理を公開する |
| A6 | 沼津市の公式ページ・会議録検索システム・議会中継へリンクする |
| A7 | 議会だよりの文章を、引用の要件（明瞭区別・主従関係・出所明示）を満たす形で引用する |

### 7.2 避けること（設計上の制約）

| # | 制約 | 理由 |
| :-- | :-- | :-- |
| **N1** | **議員個人の発言だけを集めたページ・アーカイブを作らない** | 40条1項ただし書き「同一の著作者のものを編集して利用する場合」に該当。**1項説・2項説のいずれに立っても不可** |
| N2 | 会議録の全文をそのままユーザーに配信しない | 40条の解釈が割れているため。原文は公式サイトへリンクする |
| N3 | 議会中継の映像ファイルを転載・再配信しない | 職務著作として沼津市に帰属 |
| N4 | 議会だより・議案 PDF を丸ごと再配布しない | 32条2項が禁止表示により使えない |
| N5 | 議案審議結果 PDF の表レイアウトをそのまま模倣しない | 編集著作物性の議論を回避 |
| N6 | 議員の自宅住所・電話番号を取り込まない | 個人情報 |
| N7 | 30条の4で取得した原文を、解析目的を超えて配信しない | 「享受目的」になると30条の4の枠外 |

> **N1 は計画書 9章 Q7（一般質問を扱うか）に直接効く。** 一般質問を「議案ごとの論点」として扱うのは問題ないが、「○○議員の質問一覧」というページ構成は避ける。議員ページを作る場合は、**発言そのものではなく、賛否・所属委員会・質問した議案（事実）へのリンク集**に留める。

### 7.3 実装への反映（スキーマ変更）

計画書 4.4 の `speeches` テーブルについて、以下を確定する。

```sql
create table speeches (
  ...
  heading text,              -- playlist の content（発言の見出し。事実に近く短い）
  -- minute_text は保存しない。解析時に都度取得して揮発的に使う（N2・N7）
  source_url text not null,  -- 沼津市の該当再生ページ
  ...
);
```

会議録全文は `speeches` に列を持たず、解析ジョブが実行時に DiscussVision API から取得 → LLM に投入 → **抽出された論点・意見のみを永続化**する。原文は保存しない。これで 30条の4 の枠内に確実に収まり、40条の解釈争いにも巻き込まれない。

計画書 9章 Q4（会議録全文を DB に保存するか）は、**保存しない（b）で確定**とする。

### 7.4 サイトへの表示

- 各議案ページに**出典**（沼津市議会の該当ページ URL）を必ず表示する
- 「本サービスは沼津市および沼津市議会の公式サービスではありません」を常時表示する
- 会議録に由来する情報には「沼津市議会が公開する**会議記録**（個人情報保護のため一部が伏せられており、正式な会議録とは異なる）に基づく」旨を明記する
- 解説が AI により生成されたものであること、および人のレビューを経ていることを明示する
- 誤りの指摘を受け付ける窓口を設ける

## 8. 市への働きかけ（方針転換）

前回の計画では「利用許諾の照会」を Phase 0 の**ブロッカー**に置いた。これを次のように改める。

| 前回 | 今回 |
| :-- | :-- |
| 「使わせてください」と許諾を求める。回答が来るまで実装を止める | 実装は**止めない**（7章の制約下で適法に進行）。市には別トラックで**オープンデータ化を提案**する |

**提案の骨子**

1. 議案の一覧・議決結果を CSV/API で公開してほしい（項目案: 定例会・議案番号・件名・種別・提出者・付託委員会・委員会審査結果・議決日・議決結果・議案本文 URL）
2. **同じ静岡県内の御殿場市が、議事課の手で「市議会の状況」を CC BY で公開している**（6.4）。ふじのくにオープンデータカタログの既存基盤にそのまま載せられる
3. 政府の「オープンデータ基本指針」「公共データ利用規約」が CC BY 互換を標準としている（6.2・6.3）
4. サイトの著作権表示について、**議会情報の部分だけでも二次利用可の扱いを検討してほしい**（現在の包括表示は、著作権が発生しない条例本文や、議員個人に帰属する発言まで「沼津市に帰属」としており、正確でない）

**あわせて、事前に一報を入れる。** 法的には許諾不要でも、「こういうサービスを作ります、出典は必ず明記します、誤りがあれば直します」と先に伝えておくことは、後の関係づくりに効く。**許可を求める形にはしない**（断られたら適法な利用まで自縛することになるため）。窓口は議会事務局（議事課相当）とする。

なお、市の見解が「二次利用は一切不可」であった場合でも、7.1 の A1〜A7 は著作権法上適法である。**その場合は本書の整理を示して対話する**という構えでよい。

## 9. 残る不確実性

| # | 論点 | 状態 | 対応 |
| :-- | :-- | :-- | :-- |
| U1 | 議会での発言に40条1項が適用されるか | **学説が割れている。判例を確認できていない** | 7.2 の N1・N2 で回避する設計とし、解釈に依存しない |
| U2 | 議案審議結果 PDF に編集著作物性が認められるか | 創作性は乏しいと考えるが確定的でない | N5 でレイアウトを模倣しないことで回避 |
| U3 | 30条の4の但し書き「著作権者の利益を不当に害する」の射程 | 議会情報には市場がないため該当しにくいと考える | N7 で享受目的の利用を避ける |
| U4 | 沼津市の著作権表示が32条2項の「禁止する旨の表示」に当たるか | 当たると解して保守的に運用 | 転載はせず引用に留める |
| U5 | 条例案（議決前）の著作物性 | 否定的に解するが確定的でない | 議決後は13条1号で完全に自由。議決前の議案は要約中心に扱う |

**公開前に必ず行うこと**

- 著作権・情報法に明るい**弁護士によるレビュー**（本書と、実際の画面・データフローを見せる）
- 利用規約・プライバシーポリシー・免責事項の整備
- 誤り訂正・削除依頼の受付フローの整備

**本書は法的助言ではない。** 実サービスの公開判断は専門家のレビューを経ること。
