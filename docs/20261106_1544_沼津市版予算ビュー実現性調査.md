# 沼津市版予算ビューの実現性調査

- 作成日: 2026-11-06
- 対象サービス: みらい議会＠沼津市
- 調査対象: [政府予算ビュー（β）](https://rs-vis.team-mir.ai/) / [rs-vis](https://github.com/team-mirai-volunteer/rs-vis)
- 関連資料:
  - [沼津市の予算・決算可視化 実装計画](./20260903_1555_予算決算可視化実装計画.md)
  - [財政データ契約](./20260904_1200_fiscal-data-contract.md)
  - [議会情報の二次利用に関する著作権法上の整理](./20260816_0215_議会情報の二次利用に関する著作権法上の整理.md)

## 1. 結論

沼津市版は作れるが、同じものにはならない。「市の歳入→款→節→補助金の交付先」と
「事業者別の受注額」は公開資料で実現できる。一方、再委託構造とAI事業評価は
元データが見つからず、事業別の決算は主要建設事業に限られる。そのまま移植はできない。

政府予算ビューは行政事業レビュー（RS）の構造化データを土台にしており、沼津市に
相当する統合データはない。AGPL-3.0 のコードは約1,250ファイルあり RS の形式に
強く依存するため、コードの移植ではなくアイデアを `/finance` へ取り込む。

## 2. 機能別の実現性

| 元サイトの機能 | 沼津市版 | 根拠 |
| :-- | :-- | :-- |
| 予算の流れ（歳入→款→節） | ◎ | 款×節の表が予算・決算ともにある。予算側は取り込み済み |
| 補助金などの支出先 | ◎ | 補助金・負担金・交付金の一覧が令和3〜7年度分ある |
| 事業者別の受注額 | ○ | 静岡県共同利用の入札情報システムと随意契約一覧がある |
| 1者応札・落札率 | ○ | 工事の入札結果の詳細に予定価格と全応札者の入札額がある（1件で確認）。検索できるのは令和6〜8年度のみ |
| 基金 | ◎ | 基金の現在高と市政報告書の基金運用状況がある |
| 事業別の予算 | ○ | 令和8年度の概要書に203区分（一般経費113・事業費90）、771行 |
| 事業別の決算 | △ | 主要建設事業のみ公式の一覧がある。他は文章が中心で、金額は一部のみ |
| 事業から契約先へのつながり | △ | 共通の事業IDがなく、名称の突合による推定になる |
| 再委託の構造 | × | 公開資料が見つからない |
| AI事業評価 | × | 事務事業評価シートが見つからない。金額の評価を断定しない既存方針とも合わない |

## 3. 支出先まで追える範囲（令和6年度 一般会計 927.4億円）

| 節 | 金額 | 構成比 | 支出先の扱い |
| :-- | --: | --: | :-- |
| 扶助費 | 206.8億円 | 22.3% | 個人向けなので追わない |
| 人件費（報酬・給料・職員手当等・共済費） | 122.5億円 | 13.2% | 対象外 |
| 負担金補助及び交付金 | 114.3億円 | 12.3% | 一覧あり。約24%は「申請者」表記 |
| 委託料 | 107.5億円 | 11.6% | 一部のみ |
| 繰出金 | 101.7億円 | 11.0% | 特別会計・企業会計への内部移転 |
| 工事請負費 | 79.6億円 | 8.6% | 入札結果あり |
| 償還金利子及び割引料 | 67.2億円 | 7.2% | 市債の返済が中心 |
| 積立金 | 45.8億円 | 4.9% | 基金へ |
| その他 | 82.0億円 | 8.8% | 需用費など |

支出先の候補は負担金補助及び交付金・委託料・工事請負費の3節で、合計301.4億円
（歳出の32.5%）である。

## 4. 契約データの実態（令和6年度）

- 入札情報システム: 工事278件で109.2億円、委託87件で9.2億円。水道部の発注を含むため
  一般会計の節とは直接比較できない。法人番号が載るのは工事で78件（28%）にとどまり、
  事業者名の名寄せが必要である。委託は建設関連が中心とみられる。
- 随意契約一覧: 約430件で約77.6億円（PDFからの機械集計で単価契約は未算入）。
  相手方、理由、部課が載る。
- オープンカウンター結果: 法人番号と見積額が載る。
- シルバー人材センター等との契約: 令和3年度分から公開されている。

## 5. 制約とリスク

- 入札情報システムの検索対象は令和6〜8年度のみで、過去分は順に見えなくなるとみられる。
  取得を早く始めるほど有利である。
- 入札結果の発注機関は契約検査課と水道部だけで款に結べない。支出先までつながるのは
  補助金系のみで、契約は事業者別の画面に分ける。
- RS上の沼津市への直接支出は12.1億円で、国庫支出金192.8億円の6.3%にとどまり、
  国から市への流れは接続できない。
- 1者応札を不正のように見せない。個人名を出さない。随意契約の理由文は転載せず
  事実項目だけを扱う。
- 金額や契約相手は事実として扱えるが、本家の名称・商標は使わない。コードを流用する
  場合は AGPL の表示を維持する。

## 6. 推奨する進め方

1. 既存 `/finance` の拡張（款×節の決算、歳入→款→節のサンキー図）
2. 補助金・負担金・交付金の可視化（5年分）
3. 基金ビュー
4. 契約データの蓄積と事業者別ビュー
5. 予算事業と契約の突合（推定と明示する）

議案ページとつなぎ、補正予算の補助金の行き先までたどれるようにすれば、元サイトに
ない独自の強みになる。

## 7. プロトタイプ

段階1・2の一部を `/finance/2024/flow` に試作した。DBや財政stagingを経由しない静的
データで動かし、見え方と資料の読み取り精度を確かめることを目的とする。

- データ生成: `node scripts/generate-spending-flow-data.mjs`（`pdftotext` が必要）。
  公式の件数・合計と一致しなければ失敗し、データを書き出さない。
- 検算結果: 歳入 96,520,466千円、歳出 92,736,569千円。節×款の全行・全列が一致した。
  3一覧は 237件・385件・24件で金額も公式と一致した（補助金は端数調整2千円を含む）。
  3一覧の合計は節の額と10千円差で、千円未満の丸めによるとみられる。
- 資料の表記: 「駅整備部」は資料どおり。部が空欄の行（危機管理課ほか24件）は推測で埋めない。
- 図の性質: 歳入と款の間は一般会計に合流するだけで、どの財源がどの分野に充てられたかは
  示さない。
- 本実装で必要なこと: 財政データ契約に沿った取り込み、他年度への対応、公開版管理。

## 8. 事業別の決算と契約先の検証（令和6年度）

`/finance/2024/projects` に試作した。データは
`node scripts/generate-project-budget-data.mjs` で生成する。

| 項目 | 結果 | 確度 |
| :-- | :-- | :-- |
| 事業別の当初予算 | 概要書から617行、531.8億円（当初予算879.6億円のうち）。行のある目は内訳が一致し、13款すべてで目の合計が一致。内訳の行がない8目（197.2億円、元金・繰出金など）は内訳を検算できない | 公式どおり |
| 主要建設事業の決算 | 附表から79事業、151.3億円。全行で財源の合計が決算額と一致。77事業に当初予算を対応付け。予算と決算で範囲が違う事業がある（例: 河川維持事業） | 金額は公式どおり、対応付けは要確認 |
| その他の事業の決算 | 市政報告書の文章からの自動抽出は別の事業の金額を拾うため不採用 | 不可 |
| 補助金など→事業 | 646件中206件、47.1億円（41.2%） | 名称による推定 |
| 随意契約→事業 | 408件中65件、26.7億円（34.5%） | 名称による推定 |

- 予算概要書の説明欄に委託名や交付先が書かれていることが、紐づけの手がかりになる。
  文字3-gramの一致度0.6以上、担当部と款の対応、契約額が予算額の1.3倍以下を条件にした。
- 主に金額の大きい紐づけと契約の全件を目視で確認したが、補助金などの全件は確認していない。
  誤りの例として、沼津商工会議所運営事業補助金が周年記念の事業に結び付く。一般経費の
  「委託料」へ結び付いた行は、事業の特定まではできていない。
- 随意契約のみが対象で、入札は含まない。入札情報システムは利用規約の確認が先である。
- 契約額は単年度の支出額ではない。翌年度分の契約や単価契約を含むため決算と比較しない。
- 相手方は、団体と判別できない行を伏せた（26件）。社名が途中で
  切れる行、住所の断片や品名が混ざる行が残る。本実装では行単位のQAが必要である。
- 本実装で必要なこと: 他年度への対応、人手で確定した紐づけの保存、解析精度の向上。

## 9. ローカルでの財政データ投入

`--target=fiscal` は `kessan2020/` の資料が404になり途中で止まる。令和2年度の決算概要と
市政報告書は市のサイトから消えているため、profileの見直しが必要である。公開反映の
`apply_verified_fiscal_staging` はアプリから呼ばれておらず、手動の適用手段もない。
議会費と決算概要の8バッチは一次根拠がなく、適用できない（既知の残作業）。

## 10. 未確認の点

- 物品・役務の競争入札の結果が網羅的に公開されているか。委託料のカバー率は未算出。
- 事務事業評価は検索と関連ページで見つからなかっただけで、存在しないとは断定できない。
- 入札情報システムの利用規約。自動取得の前に確認が必要である。
- 元サイトは各ページのタイトルと README が中心で、投稿の動画は見ていない。
