# 一般質問可視化 データ契約・分類ガイド

- 対象: みらい議会＠沼津市
- 初版: 2026-09-04
- 分類体系: `numazu-policy-v1`

## 指標

| 表示名 | 数え方 | 比較上の制約 |
| :-- | :-- | :-- |
| 一般質問実施日数 | QA済みで公開中の、実開催日がある本会議の日付の異なり数 | 会議時間や質問量を表さない |
| 登壇枠数 | 公式PDFの質問順1枠、PDFがない期間はQA済み会議記録の登壇1枠を1件とする | 個人別ランキングや評価に使わない |
| 質問項目数 | 公式PDFの最上位項目を数える | 資料の書き方が異なるため質問量の比較に使わない |
| 政策分野構成 | active releaseに含まれるQA済み項目の複数分類 | 複数分野を許すため合計は100%にならない場合がある |
| 答弁者掲載枠数 | 同じ登壇枠に役職が掲載された異なり枠数 | 答弁回数、個別項目への帰属、十分性を表さない |

`未取得`、`公式資料未公開`、`解析エラー`、`実施なし`、`0件`は相互に変換しない。
`実施なし`は公式資料を人手確認した場合だけ公開できる。

## 公開しない比較

- 一般質問数、登壇回数、項目数、文字数、時間による市議会議員ランキング
- 質問の鋭さ、成果、影響、活動量を表すスコア
- 会派・党派と質問内容を結び付けた自動評価
- 現在の所属を過去の登壇へ遡及適用した集計

## 政策分野 v1

一つの項目に複数分野を付けられる。主分野は強制しない。分類は項目の公式表記が直接扱う
行政課題を基準にし、想定される政治的意図や成果を推測しない。

| 分野 | 含める例 | 境界 |
| :-- | :-- | :-- |
| 防災・危機管理 | 地震、避難所、消防、救急、防犯 | 道路整備のみなら都市・インフラ |
| 子育て・教育 | 保育、学校、教育環境、生涯学習 | 医療的ケア自体は医療・福祉も併記可 |
| 医療・福祉 | 健康、病院、高齢者、障害者、生活支援 | 子ども施策は子育て・教育も併記可 |
| 産業・観光 | 商工、雇用、農林水産、観光 | 公共施設整備が中心なら都市・インフラも検討 |
| 環境・脱炭素 | 廃棄物、自然環境、温室効果ガス、エネルギー | 災害対応が中心なら防災・危機管理 |
| 都市・インフラ | 都市計画、道路、公園、住宅、上下水道 | 公共資産の経営が中心なら財政・公共資産も併記可 |
| 地域・文化・スポーツ | 地域自治、文化、スポーツ、多文化共生 | 市民参加制度は人権・市民参加も検討 |
| デジタル・行政運営 | 行政DX、組織、人材、情報公開 | 個別分野の単なる機器導入では当該分野を優先 |
| 財政・公共資産 | 予算、財源、財政運営、公共施設再編 | 個別事業の内容を扱う場合は該当政策分野も併記可 |
| 人権・市民参加 | 人権、男女共同参画、市民参加、選挙 | 地域団体の活動支援は地域・文化・スポーツも検討 |

## QAと訂正

PDFの会期、日付、質問順、氏名、方式、階層、最上位項目数、答弁者役職を照合する。
分類と短い表示文は原文の趣旨を超えないことを確認する。訂正時は既存の公開revisionを
直接書き換えず、新revision・新分類set・新releaseを作って旧版をsupersededにする。
すべての公開parser根拠は保持中の原本、取得版、解析実行、QA担当へ遡及できなければならない。

## 期間別の取得方法

- 2004年以降は一般質問資料PDFを基幹資料とし、取得原本を非公開Storageへ保持する。
- 1990年以降でPDFがない期間は、市公式案内から遷移できる会議記録を補完資料にする。
  会議種別・一般質問区間・登壇者・答弁者役職を人手確認し、PDF由来と同等の項目完全性は
  仮定しない。
- 会議記録本文は解析中だけ利用し、DBやStorageへ永続化・再掲載しない。取得版には
  ハッシュ、取得日時、公式URL、非保持状態だけを記録する。
- PDFと会議記録が重なる場合は自動結合せず、同じ公開会期・開催日の候補から確認者が
  同一の会議・登壇枠を明示的に選ぶ。
